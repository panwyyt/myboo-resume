# Selenium

Web UI automation with Robot Framework and SeleniumLibrary

## Capabilities

- Write keyword-driven tests with Robot Framework and SeleniumLibrary (Python) driving Selenium WebDriver
- Structure code with the Page Object Model (POM) using user keywords and resource files for easy maintenance and scaling
- Use multiple locator strategies: id, name, XPath, CSS, link, class
- Handle every element type: text fields, dropdowns, checkboxes/radios, file upload, and date-pickers
- Manage alerts, iframes, and dynamic elements with explicit/implicit waits to reduce flaky tests (e.g. fixing a stuck date-picker by overwriting the value)
- Data-driven testing with Test Templates and external data
- Cross-browser runs (Chrome, Firefox, Edge) and headless execution
- Parallel and distributed runs with Selenium Grid and Pabot
- Read report.html / log.html with on-failure screenshots, and integrate with CI/CD (Jenkins, GitHub Actions)

**Stack:** Robot Framework, SeleniumLibrary, Python
**Certifications:** Automation Test (Basic), Automation Test (Advanced)
