# Postman

API testing

## Capabilities

- Test REST APIs across full CRUD (GET/POST/PUT/PATCH/DELETE) with assertions on status code, response time, body, and schema
- Write test scripts with pm.test() and pm.expect() (Chai), plus pre-request scripts for dynamic data, timestamps, and request signing
- Validate responses with JSON Schema
- Use environment / global / collection variables to run across dev/staging/prod
- Extract tokens and chain authentication (Bearer / OAuth 2.0) across requests
- Organize requests into collections, folders, and workspaces for maintainability
- Run automated suites with the Collection Runner (iterations and delays) and data-driven testing with CSV/JSON
- Import from Swagger/OpenAPI and convert cURL into requests
- Run headless with the Newman CLI and integrate with CI/CD
- Use mock servers and monitors to simulate responses and check API health

**Certifications:** API Testing with Postman (Basic)
