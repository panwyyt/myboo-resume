# Manual Testing

Test design and quality assurance from the user's point of view

## Capabilities

- Design test scenarios and test cases from requirements, user stories, and UI mockups; start testing before code exists (shift-left)
- Apply standard test design techniques: Equivalence Partitioning, Boundary Value Analysis, Decision Tables, and State Transition
- Exploratory testing and error guessing to catch cases the documentation misses
- Functional / UI testing of real flows such as search, filter, and registration, covering positive and negative paths and input validation
- Regression testing after changes, plus UAT support
- Reproducible bug reports: steps, expected vs actual, environment, and evidence
- Severity / Priority triage and defect lifecycle tracking through to closure
- Test plans and a Requirements Traceability Matrix (RTM) to keep coverage complete
- Data-driven quality reporting (pass/fail, coverage, defect trends), backed by a Data Analyst foundation

**Certifications:** Manual Testing (Software Testing by P'Beam), Certified Professional Data Analyst
