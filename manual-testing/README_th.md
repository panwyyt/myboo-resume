# Manual Testing

การออกแบบการทดสอบและประกันคุณภาพจากมุมมองของผู้ใช้

## สิ่งที่ทำได้

- ออกแบบ Test Scenario และ Test Case จาก requirement, user story และ UI mockup เริ่มทดสอบได้ตั้งแต่ก่อนมีโค้ด (แนว shift-left)
- ใช้เทคนิคออกแบบเทสมาตรฐาน: Equivalence Partitioning, Boundary Value Analysis, Decision Table และ State Transition
- Exploratory testing และ error guessing เพื่อจับเคสที่เอกสารตกหล่น
- Functional / UI testing ของโฟลว์จริง เช่น ค้นหา ตัวกรอง และฟอร์มลงทะเบียน ครอบคลุมทั้ง positive/negative path และ input validation
- Regression testing หลังการแก้ไข และสนับสนุนการทำ UAT
- เขียน bug report แบบ reproducible: ขั้นตอนการเกิด, ผลที่คาดหวังเทียบกับผลจริง, environment และหลักฐานประกอบ
- จัดระดับ Severity / Priority และติดตาม defect lifecycle จนปิดงาน
- ทำ Test Plan และ Requirements Traceability Matrix (RTM) เพื่อคุม coverage ให้ครบ
- สรุปคุณภาพเป็นรายงานเชิงข้อมูล (pass/fail, coverage, defect trend) ด้วยพื้นฐาน Data Analyst
