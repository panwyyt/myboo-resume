# AI Engineering

Configuring and connecting AI agents to real work: MCP, Agent Skills, and context engineering

## Capabilities

- Set up and use the Model Context Protocol (MCP) to connect AI assistants to external apps, APIs, and data sources
- Build MCP servers that expose tools, resources, and prompts so agents can call functions, read data, and reuse prompts
- Configure AI coding agents with project instruction files: CLAUDE.md, GEMINI.md, and the cross-tool AGENTS.md standard
- Author Agent Skills (SKILL.md) that package instructions, scripts, and resources into on-demand capabilities
- Apply context engineering to manage the context window through retrieval, summarization, and compaction for long-running agents
- Implement persistent memory so agents retain knowledge across sessions
- Design multi-step agentic workflows using tool use / function calling to automate tasks end to end
- Orchestrate subagents with isolated context windows that return condensed results to a lead agent
- Integrate AI with external systems such as Git/GitHub, Slack, databases, and browsers via MCP and APIs
- Apply agentic AI to QA: AI-assisted test generation, exploration, and self-healing tests
- Write effective prompts and tooling for reliable, reproducible automation in testing pipelines
