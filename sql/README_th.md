# SQL

Database Testing และ Data Validation

## สิ่งที่ทำได้

- ตรวจ CRUD ที่ชั้นข้อมูล และเทียบสถานะที่แสดงใน UI กับข้อมูลจริงในฐานข้อมูลให้ตรงกัน
- เขียน query ตรวจสอบ: multi-table JOIN (INNER/LEFT/RIGHT), aggregation กับ GROUP BY (COUNT/SUM/AVG), filter, sort และ CASE WHEN
- ตรวจ data integrity (type, format, range, NOT NULL, unique) และ referential integrity (foreign key, ความสัมพันธ์ 1:N)
- เขียน query ขั้นสูง: CTEs และ Window Functions (RANK, LEAD, LAG, running total)
- หา duplicate, orphaned record และ NULL/anomaly ด้วย query
- ทำงานกับชุดข้อมูลขนาดใหญ่ (10,000+ แถว) เพื่อตรวจความถูกต้องและความครบถ้วน
- อ่าน ER Diagram และออกแบบ/ตรวจ schema (table, key, constraint) เพื่อจับบั๊กระดับโครงสร้าง
- เข้าใจการตรวจ transaction / ACID และแนวทางการทดสอบ data migration
- ใช้ PostgreSQL ผ่าน VSCode Database Tools และ pgAdmin4

**ใบรับรอง:** SQL Certification
