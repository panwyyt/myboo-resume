# SQL

Database testing and data validation

## Capabilities

- Validate CRUD at the data layer and reconcile UI state against the actual database
- Write verification queries: multi-table JOINs (INNER/LEFT/RIGHT), aggregations with GROUP BY (COUNT/SUM/AVG), filtering, sorting, and CASE WHEN
- Check data integrity (type, format, range, NOT NULL, unique) and referential integrity (foreign keys, 1:N relationships)
- Write advanced queries: CTEs and Window Functions (RANK, LEAD, LAG, running totals)
- Find duplicates, orphaned records, and NULL/anomaly patterns with queries
- Work with large datasets (10,000+ rows) to verify accuracy and completeness
- Read ER diagrams and design/validate schema (tables, keys, constraints) to catch structural bugs
- Understand transaction/ACID validation and data migration testing
- Use PostgreSQL via VSCode Database Tools and pgAdmin4
